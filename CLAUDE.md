# Arab RP — инструкции для Claude Code

Мобильная мультиплеерная RP-игра в стиле Black Russia с арабскими городами: Амман, Эр-Рияд, Дубай, Доха, Джидда.
Клиент — браузер (three.js), сервер — Node.js + WebSocket. Живая версия: https://arab-rp.onrender.com.
Каждый push в `main` Render выкладывает сам (сервис `arab-rp`).

Владелец проекта говорит по-русски и не программист. Отвечай по-русски, коротко и простыми словами.

## Запуск
```bash
npm install
npm start                          # http://localhost:3000
NO_ANTICHEAT=1 npm start           # для тестов: разрешает телепорт
```

## Файлы
| Файл | Что внутри |
|---|---|
| `server.js` | WebSocket-сервер: профили, деньги, работа, покупки, еда, смерть, античит |
| `public/shared/world.js` | Общий детерминированный мир: города, дороги, рельеф, машины, точки интереса. Без DOM/three: его импортирует и сервер |
| `public/js/build.js` | Построение статичного мира: склейка в чанки, LOD, коллизии, маркеры |
| `public/js/main.js` | Игровой цикл, ввод, физика пешком и в машине, камера, сеть, HUD, радар |
| `public/js/cars.js` | Машины: процедурные и GLB-модели (`public/models/*.glb`) |
| `public/js/human.js` | Персонаж со скелетом (Quaternius CC0), тоб, шемаг, анимации |
| `public/js/char.js` | Простой запасной персонаж |
| `tools/usdz2glb.py` | Конвертер моделей машин из USDZ в GLB |

## Правила
- Деньгами и имуществом распоряжается только сервер. Клиент шлёт намерение, сервер проверяет.
- Новое или изменённое сетевое сообщение — правится в `server.js` и `main.js` в одном коммите.
- Все тексты интерфейса берутся из словаря `T` в `main.js` (арабский по умолчанию плюс русский).
- Бюджет телефона: при графике «низкая» не больше 150 draw calls и 450 тыс. треугольников. Мелкие детали — в LOD-слоях.
- Модели: GLB + meshopt + webp. У машины материал кузова называется `paint`, колёса — узлы `wheel_FL/FR/RL/RR`.
- Чужие ассеты кладутся вместе с лицензией. Модели из GTA и BR не берём.
- Перед пушем проверь в браузере: вход, ходьба, машина, доставка, автосалон, двое игроков, экран 844×390.

## Известные долги
- `main.js` слишком большой. Пора разнести его на `net.js`, `input.js`, `physics.js`, `camera.js`, `hud.js`, `minimap.js`.
- Профили лежат в `data/profiles.json` и стираются при перезапуске Render. Нужно перенести их в базу (Supabase).
- Звука, NPC и водителя в машине пока нет.
