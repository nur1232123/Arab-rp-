# Arab RP — عرب رول بلاي

Мобильная мультиплеерная RP-игра в браузере. Тестовая версия.

**Что есть (v0.2):**
- **Персонаж:** управление в духе классических GTA — быстрый разгон и повороты, разворот на месте, камера сама заходит за спину; бег с выносливостью (Shift или кнопка), прыжок, перелезание через заборы и машины (прыжок у препятствия), игроки не проходят друг сквозь друга.
- **Машины:** автосалоны трёх классов (эконом, средний, элитный), бензин и АЗС, поломки от ударов, техцентр (ремонт и тюнинг двигателя на 3 уровня).
- **Магазины:** магазин 24/7 (вода, сэндвич, аптечка, канистра, ремкомплект — в сумку), ларьки на улицах, сумка с вещами. Можно сесть в машину и выйти из неё (F). Четыре цвета кожи.
- **Одежда:** тоб (9 цветов), бишт, костюм, спортивный, повседневная; шемаг красный и чёрный, гутра, такия, кепка; борода и очки. Подол и шемаг колышутся на ходу. Платные вещи — в магазине одежды (фиолетовый маркер).
- **Работа и покупки:** доставка с GPS-маршрутом и клиентом у двери, грузчик на складе, такси между городами ($250), 3D-автосалон с тест-драйвом.
- **Звук:** мотор, шаги, удары, гудок (H), кнопки — всё синтезируется в браузере.
- **Камера как в GTA:** обзор пальцем по экрану или мышью. Камера не проходит сквозь стены.
- **Карта 8×8 км, 5 городов:**
  - Амман на холмах, с флагштоком;
  - Эр-Рияд с башней-аркой;
  - Дубай с мегабашней;
  - Доха с башней-«пулей»;
  - Джидда с фонтаном в море.
- **В городах:** тротуары с бордюрами, фонари, светофоры, зебры, мечети с минаретами. На домах баки для воды, кондиционеры и балконы. Есть магазины с арабскими вывесками, виллы с заборами, парки и парковки.
- **Между городами:** трассы с фонарями и указателями, заправки, деревни, горы и ущелья, верблюды, кусты и камни.
- **Смена дня и ночи** (24 минуты). Ночью горят окна, фонари и фары.
- **Интерфейс в стиле BR:** деньги, здоровье, сытость, часы, радар, спидометр.
- **Экономика:** работа доставщиком, автосалон на 4 машины, шаурма от голода, больница при нуле здоровья.
- **Мультиплеер:** игроки видны с никами (пешком и в машинах), есть чат.
- **Настройки графики** (низкая/высокая), языки: арабский и русский.

## Запуск у себя

```bash
npm install
npm start      # http://localhost:3000
```

## Как устроено

| Файл | Что внутри |
|---|---|
| `server.js` | сервер: WebSocket, игроки, деньги, работа, покупки, защита от телепортов |
| `public/shared/world.js` | общий для клиента и сервера мир: города, дороги, рельеф, машины |
| `public/js/build.js` | 3D-мир: здания, дороги, пальмы, достопримечательности |
| `public/js/cars.js` | модели машин |
| `public/js/human.js` | настоящий персонаж (скелет, анимации, тоб и шемаг) |
| `public/js/char.js` | простой персонаж, пока грузится настоящий |
| `public/js/main.js` | клиент: управление, физика, сеть, интерфейс |

Профили игроков пока хранятся в `data/profiles.json`. На бесплатном Render этот файл стирается при перезапуске сервера. Следующий шаг — перенести профили в базу данных (Supabase).

## Чужие ресурсы и лицензии

- **Персонаж и анимации:** Quaternius — Universal Base Characters и Universal Animation Library, лицензия CC0. Файлы лежат в `public/models/human/`, тексты лицензий там же.
- **Машины «Сахм» и «Асифа»:** модели с Sketchfab, их прислал владелец проекта. Перед публичным запуском нужно проверить лицензию и указать авторов.
- **Three.js:** лицензия MIT.
