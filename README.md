# Arab RP — عرب رول بلاي

Мобильная мультиплеерная RP-игра в браузере. Тестовая версия.

**Что есть:**
- Карта 8×8 км: Амман (холмы, флагшток), Эр-Рияд (башня с аркой), Дубай (небоскрёбы, мегабашня), Доха (круглые башни), Джидда (фонтан в море). Города соединены пустынными трассами, по краям карты Персидский залив и Красное море.
- 4 машины: غزال седан, ذيب пикап, صقر внедорожник, برق спорткар, плюс 8 цветов.
- Работа доставщиком: жёлтый маркер в каждом городе. Заказы по своему городу и между городами.
- Автосалон: синий маркер.
- Мультиплеер: видно других игроков с никами, работает чат.
- Управление с телефона (джойстик, газ, тормоз) и с клавиатуры (WASD, E, M, C, T).
- Интерфейс на арабском, есть переключатель на русский.

## Запуск у себя

```bash
npm install
npm start      # http://localhost:3000
```

## Как устроено

| Файл | Что внутри |
|---|---|
| `server.js` | сервер: WebSocket, игроки, деньги, работа, покупки, защита от телепортов |
| `public/shared/world.js` | общий для клиента и сервера мир: города, дороги, рельеф, машины |
| `public/js/build.js` | 3D-мир: здания, дороги, пальмы, достопримечательности |
| `public/js/cars.js` | модели машин |
| `public/js/main.js` | клиент: управление, физика, сеть, интерфейс |

Профили игроков пока хранятся в `data/profiles.json`. На бесплатном Render этот файл стирается при перезапуске сервера. Следующий шаг — перенести профили в базу данных (Supabase).
